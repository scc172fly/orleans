## [Blazor 服务器](./BlazorServer/#readme) 和 [布拉佐尔 WebAssembly](./BlazorWasm/#readme) 样本

:::image type="content" source="BlazorWasm/screenshot.jpeg" alt-text="布拉佐 WebAssembly 样本。":::

这两个布拉佐样本以 [布拉佐尔入门辅导](https://dotnet.microsoft.com/learn/aspnet/blazor-tutorial/intro)为基础,经调整后与 Orleans一起使用。 [布拉佐尔 WebAssembly](./BlazorWasm/#readme) 样本使用 [Blazor WebAssembly 主机模式](https://docs.microsoft.com/aspnet/core/blazor/hosting-models#blazor-webassembly)。 [Blazor 服务器](./BlazorServer/#readme) 样本使用 [Blazor 服务器主机模式](https://docs.microsoft.com/aspnet/core/blazor/hosting-models#blazor-server),其中包括一个互动柜台、一个TODO清单和一个气象服务。
