## [Blazor Server](./BlazorServer/#readme) 和 [Blazor WebAssembly](./BlazorWasm/#readme) 示例

:::image type="content" source="BlazorWasm/screenshot.jpeg" alt-text="Blazor WebAssembly sample.":::

这两个 Blazor 示例基于 [Blazor 入门教程](https://dotnet.microsoft.com/learn/aspnet/blazor-tutorial/intro)，并进行了调整以配合 Orleans 使用。[Blazor WebAssembly](./BlazorWasm/#readme) 示例使用 [Blazor WebAssembly 托管模型](https://docs.microsoft.com/aspnet/core/blazor/hosting-models#blazor-webassembly)。[Blazor Server](./BlazorServer/#readme) 示例使用 [Blazor Server 托管模型](https://docs.microsoft.com/aspnet/core/blazor/hosting-models#blazor-server)。它们包含交互式计数器、待办事项列表和天气服务。

* 如何将 ASP.NET Core Blazor WebAssembly (WASM) 与 Orleans 集成
