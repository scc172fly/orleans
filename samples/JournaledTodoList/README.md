## 运行样本

安装 .NET 10 SDK、 占卜器 CLI和与多克兼容的容器运行时间。
从此目录运行 :

```powershell
aspire run --project JournaledTodoList.AppHost
```

打开在星盘仪表板中显示的 `webapp` 终点。添加、完成和删除
要练习已日记的待办事宜列表 grain的项目。
