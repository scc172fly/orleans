<a id="features-for-stateful-distributed-applications"></a>

## 用于有状况分布式应用程序的特征

Orleans 将分布式方案拟订模式与建设和运行状态服务运行时间能力结合起来,在整个 Microsoft 用于大规模运行关键服务。

<CardGrid>
  <Card title="虚拟行为体" icon="puzzle">
    示范应用实体为 grains ,具有稳定身份、孤立行为和以转手方式执行。 [探索 grains](/orleans/docs/grains/)。
  </Card>
  <Card title="国家 永久状态" icon="database">
    持久性 grain 提供方的状态 AzureAWS,谷歌云,关系数据库 Redis和自定义储存系统。 [探索持久性](/orleans/docs/grains/grain-persistence/).
  </Card>
  <Card title="流和事件处理" icon="random">
    利用有管理、持久或模拟流供应商连接生产者和消费者。 [探索流流](/orleans/docs/streaming/)
  </Card>
  <Card title="长期安排和执行" icon="clock">
    运行启动范围回馈、重复的耐用提醒和一次性分配的工作。探索 [计时和提醒](/orleans/docs/grains/timers-and-reminders/) 和 [持久就业](/orleans/docs/resources/nuget-packages/#durable-state-jobs-messaging-and-tasks)。
  </Card>
  <Card title="交易交易" icon="approve-check">
    使用ACID交易,对 grains 之间具有可连号隔离的持久性支持状态进行协调。 [探索交易](/orleans/docs/grains/transactions/)。
  </Card>
  <Card title="事件来源" icon="code-branch">
    表示 grain 状态,使用可配置的对数一致性提供者作为事件顺序排序。 [探索活动来源](/orleans/docs/grains/event-sourcing/)。
  </Card>
  <Card title="弹性缩放和负负平衡" icon="analytics">
    在资源意识定位引导新启动、记忆压力下裁回能力以及选择参与平衡或重新分配迁移符合启动条件的同时,添加或删除 silos 。 [探索安置和负载平衡](/orleans/docs/grains/grain-placement/)
  </Card>
  <Card title="失责容忍度" icon="server">
    检测失败 silos 和重新启动 grains 恢复健康宿主的状态 以耐久储存方式 [探索集群和复苏](/orleans/docs/overview/#silos-and-clusters).
  </Card>
</CardGrid>

<a id="programming-model"></a>

## 方案拟订模式

定义 grain 合同,将其作为普通 .NET 类执行,从组群中任何地方调用。

<div class="home-code-grid">
  <div>
    <p class="home-code-label">定义 grain</p>
    <Code code={`public interface ICounter : IGrainWithStringKey
{
    Task<int> Add(int value);
}

public sealed class Counter : Grain, ICounter
{
    private int _value;

    public Task<int> Add(int value) =>
        Task.FromResult(_value += value);
}`} lang="csharp" title="Counter.cs" />
  </div>
  <div>
    <p class="home-code-label">从客户端或其他客户端调用 grain</p>
    <Code code={`var counter = client.GetGrain<ICounter>("orders");
var total = await counter.Add(1);`} lang="csharp" title="Program.cs" />
  </div>
</div>
