<a id="features-for-stateful-distributed-applications"></a>

## 有状态分布式应用的功能

Orleans 提供构建和运行有状态服务所需的分布式编程模型和运行时功能。Microsoft 使用它大规模运行关键业务服务。

<CardGrid>
  <Card title="虚拟 Actor" icon="puzzle">
    将应用实体建模为 Grain。每个 Grain 都有稳定的标识、隔离的行为，并按轮次执行。[了解 Grain](/orleans/docs/grains/)。
  </Card>
  <Card title="持久化状态" icon="database">
    使用 Azure、AWS、Google Cloud、关系型数据库、Redis 或自定义提供程序持久化 Grain 状态。[了解持久化](/orleans/docs/grains/grain-persistence/)。
  </Card>
  <Card title="流和事件处理" icon="random">
    使用托管、持久化或内存流提供程序连接生产者与消费者。[了解流处理](/orleans/docs/streaming/)。
  </Card>
  <Card title="持久化调度与执行" icon="clock">
    运行激活范围内的回调、周期性持久化提醒器和一次性分布式作业。[定时器与提醒器](/orleans/docs/grains/timers-and-reminders/)和[持久化作业](/orleans/docs/resources/nuget-packages/#durable-state-jobs-messaging-and-tasks)。
  </Card>
  <Card title="事务" icon="approve-check">
    通过具有可串行化隔离级别的 ACID 事务，协调不同 Grain 中受支持的持久化状态。[了解事务](/orleans/docs/grains/transactions/)。
  </Card>
  <Card title="事件溯源" icon="code-branch">
    通过可配置的日志一致性提供程序，将 Grain 状态表示为有序的事件序列。[了解事件溯源](/orleans/docs/grains/event-sourcing/)。
  </Card>
  <Card title="弹性伸缩与负载均衡" icon="analytics">
    添加或移除 Silo 时，感知资源的放置策略负责安排新的激活实例；内存压力下的负载削减可回收容量，主动启用负载均衡或重新分区后还可迁移符合条件的激活实例。[了解放置与负载均衡](/orleans/docs/grains/grain-placement/)。
  </Card>
  <Card title="容错" icon="server">
    检测 Silo 故障，在健康主机上重新激活 Grain，并恢复已写入持久存储的状态。[了解集群与恢复](/orleans/docs/overview/#silos-and-clusters)。
  </Card>
</CardGrid>

<a id="common-application-scenarios"></a>

## 常见应用场景

当应用包含大量可独立寻址的实体，且状态与工作可以按标识划分时，Orleans 尤其适用。[查看完整的应用场景与用例指南](/orleans/docs/scenarios/)。

<CardGrid>
  <Card title="AI 智能体与对话会话" icon="comment-alt">
    为每个智能体会话管理对话状态、工具配置、待处理任务与协调工作。[了解 AI 智能体场景](/orleans/docs/scenarios/#ai-agents-and-conversational-sessions)。
  </Card>
  <Card title="欺诈、风险和实时决策" icon="padlock">
    根据快速变化的账户、市场、策略或事件状态进行低延迟决策。[了解实时决策场景](/orleans/docs/scenarios/#fraud-protection-risk-and-low-latency-decisioning)。
  </Card>
  <Card title="物联网与数字孪生" icon="mobile-android">
    用稳定标识、不断演进的状态、有序命令和定时工作表示设备与资产。[了解物联网场景](/orleans/docs/scenarios/#internet-of-things-and-digital-twins)。
  </Card>
  <Card title="监控与作业编排" icon="analytics">
    跟踪资源、运行状况、配额、作业、依赖关系、重试和长期进度。[了解作业编排场景](/orleans/docs/scenarios/#monitoring-resource-governance-and-job-orchestration)。
  </Card>
  <Card title="多人游戏与在线游戏" icon="star">
    管理玩家、房间、对局、在线状态、成长进度与权威会话状态。[了解游戏场景](/orleans/docs/scenarios/#multiplayer-and-online-games)。
  </Card>
  <Card title="商业交易与预订" icon="database">
    管理购物车、订单、账户、预订、订阅和客户上下文。[了解商业场景](/orleans/docs/scenarios/#commerce-reservations-and-customer-services)。
  </Card>
</CardGrid>

<a id="programming-model"></a>

## 编程模型

定义 Grain 契约，用普通 .NET 类实现它，再从集群中的任意位置调用。

<div class="home-code-grid">
  <div>
    <p class="home-code-label">定义 Grain</p>
    <Code code={`public interface ICounter : IGrainWithStringKey
{
    Task<int> Add(int value);
}

public sealed class Counter : Grain, ICounter
{
    private int _value;

    public Task<int> Add(int value) =>
        Task.FromResult(_value += value);
}`} lang="csharp" title="Counter.cs" />
  </div>
  <div>
    <p class="home-code-label">从客户端或其他 Grain 调用 Grain</p>
    <Code code={`var counter = client.GetGrain<ICounter>("orders");
var total = await counter.Add(1);`} lang="csharp" title="Program.cs" />
  </div>
</div>
