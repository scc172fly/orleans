# Orleans API 参考指南

[C# API 参考](https://dotnet.github.io/orleans/docs/api/csharp/) 是 Orleans 公共类型和成员的完整引用。 当您需要精确的签名、超载、默认、例外或继承关系时使用它 。

参考页对周围文件非常有用:

- 在 [Orleans 概览](../overview.md)、 [开发 Orleans grains](../grains/index.md)和 [与 Orleans串流](../streaming/index.md)中学习编程模式。
- 执行《1990年代联合国 [如何指导索引](../how-to/index.md),包括 [服务器主机配置](../host/configuration-guide/index.md) 和 [部署部署](../deployment/index.md).
- 理解 [建筑和内部](../implementation/index.md)中的运行时间保障和权衡。
- 与 [排除工作流程的麻烦](../host/monitoring/troubleshooting.md)的诊断性生产症状。

当指南中指定一个公共 Orleans 符号时,更喜欢其生成的 xref 链接。合同使用 API 参考,建议的使用和操作环境使用概念或页面或如何页。
