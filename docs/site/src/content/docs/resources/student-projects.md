# 研究和学生项目

前一项目清单介绍了研究思想和 Azure 技术的早期阶段的技术 Orleans 并充当历史背景。

关于项目设想:

- 浏览标签为 [`help wanted`](https://github.com/dotnet/orleans/labels/help%20wanted) 或 [`good first issue`](https://github.com/dotnet/orleans/labels/good%20first%20issue)的问题。
- 在 [GitHub 讨论](https://github.com/dotnet/orleans/discussions)中启动设计对话框。
- 在提议实施之前读取 [贡献指南](https://github.com/dotnet/orleans/blob/main/CONTRIBUTING.md) 。
- 探索 [Orleans 研究出版物](https://www.microsoft.com/research/project/orleans-virtual-actors/publications/)。

课程项目可以首先从 [Orleans 样本](https://github.com/dotnet/orleans/tree/main/samples) 开始,并评价重点突出的分布式系统关切问题,如分割、一致性、故障恢复、可观测性或负载分配。
