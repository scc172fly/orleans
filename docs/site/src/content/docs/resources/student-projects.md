# 研究与学生项目

先前的项目清单介绍 Orleans 早期阶段的研究构想及 Azure 技术，可作为历史背景参考。

如需项目构想：

- 浏览带有 [`help wanted`](https://github.com/dotnet/orleans/labels/help%20wanted) 或 [`good first issue`](https://github.com/dotnet/orleans/labels/good%20first%20issue) 标签的问题。
- 在 [GitHub Discussions](https://github.com/dotnet/orleans/discussions) 中发起设计讨论。
- 在提出实现方案前阅读[贡献指南](https://github.com/dotnet/orleans/blob/main/CONTRIBUTING.md)。
- 探索 [Orleans 研究出版物](https://www.microsoft.com/research/project/orleans-virtual-actors/publications/)。

课程项目可以从 [Orleans 示例](https://github.com/dotnet/orleans/tree/main/samples) 开始，评估一个特定的分布式系统问题，例如分区、一致性、故障恢复、可观测性或负载分布。
